# Picolloscope

This project is based on https://github.com/jlfwong/speedscope (MIT, commit: fe804e6281cf847713448c2c3e0faec3e1f62b2d).
It has been stripped down and heavily reworked without any attempt to keep backward compatibility, only the rendering layer is mostly intact.
It can be used only with Picollo's profiler output format now.
The format is evolving with regular breaking changes.
